# 🚀 AI Recruitment System (Free + Smart UI)

## 📝 Project Description

This is a **Smart AI Recruitment System** that analyzes resumes against job descriptions and provides selection decisions.

👉 This version is optimized for:
- ✅ No API required (Free mode)
- ✅ Clean & modern UI
- ✅ Fast resume analysis

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 📝 Enter Job Description
- 🤖 Smart Resume Analysis (Keyword-based AI logic)
- 📊 Match Score Calculation
- ✅ Selection / Rejection Decision
- 🎯 Skill Matching System
- ⚡ Fast & lightweight (No API dependency)

---

## 🛠️ Tech Stack

- Python 🐍
- Streamlit 🌐
- PyPDF2 📄
